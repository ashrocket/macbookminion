Start with the Mac you kept.

You’ll need a controlling Mac with Python 3.8+, an Intel Mac with Remote Login, and a trusted network between them.

git clone https://github.com/ashrocket/macbookminion.git
cd macbookminion
./bin/minion --help

Then follow the pairing guide to connect your worker and run a first job.

Small project. Useful purpose.

Built on MacBook Minion, an open-source SSH worker harness for Codex.

Plain Python on the controller. Ordinary shell tools on the worker. No server agent needed for shell jobs.

Good jobs for a spare Mac

  • tests & shell jobs
  • media conversion
  • bounded web research
  • browser checks

Check each worker’s installed tools before sending a job.

A few things to know

Codex stays on your main Mac. Workers add tool capacity; model subscription limits stay the same.

Jobs use the SSH account’s permissions. A dedicated standard account is recommended.
